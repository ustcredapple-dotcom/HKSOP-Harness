# 光路原理设计

输入实验目标或 graph.py。

设计只使用元件的光学端口、方向、波长、偏振和端面距离。

每次修改均用本插件的脚本重新追迹，处理 ERROR，报告仍存在的 WARNING。

交付 graph.py、trace.json、schematic.svg。

展示原理图和关键终端读数后暂停，交由用户确认并开启 hksop-step2-board。

## 保偏接口与验收

保偏出口从最后一个分束面起须有 QWP 与 HWP。入口先 QWP 消除残余椭偏，后 HWP 设第一分光比。PBS 透射直通纯 P 的级间可用单 HWP。反射、厚窗或声光级间优先双片。默认窄键 FC/APC；平端面约 4% 背反。反射支路目标 20 dB 需实测，30 dB 需清理或高消光比分束器。超过 1 W 核对石英波片及高损伤阈值光学元件。
