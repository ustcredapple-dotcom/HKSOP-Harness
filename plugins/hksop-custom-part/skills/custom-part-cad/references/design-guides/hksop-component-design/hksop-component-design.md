固定真实光学面、局部坐标、柱轴、安装孔和公制光高；项目姿态不写回器件原型。45°/90° 的接口不同就保留独立差异。实际 CAD、俯视渲染、接口 JSON 必须能对应同一装配。

保留材料、表面处理、螺纹、刀具/扳手入口、通光与运动包络的核验。制造未验收的设计以明确状态入定制包，不能因通过 JSON 校验而改成标准制造件。完成后交给 hksop-component-upload，不重复生成支持清单。

## 倒 C 角

自动设计自制加工件时，按 统一倒 C 角规则 将普通外露非功能锐边和间隙孔外孔口默认处理为 C0.3×45°。先判定功能边及材料余量，确认的倒角必须进入源模型、单件/总装 STEP 和加工图；只补本次变更及受影响检查。

AI 已经验证过的设计直接复用验收，只验证新增、变更及其直接影响的部分。此规则优先于下文及旧参考文件中的全项检查要求；新设计中尚未验证的部分仍按原设计规范完成。交接附当前修订、已有清单/哈希、验证记录和未完成项，已有图模、BOM、俯视图及入库包直接复用，不要求接收方重跑设计验收。

具体按 [验收复用与最小入库流程](../../../../../shared/acceptance-reuse.md) 执行；只补缺项或检查实际变更，不为再次入库重新测量、渲染、逐页复查或测试未变元件。
