# heritage

- 引擎保留当前有效实现；现用元件进入正常选择列表。每次更新按用户当次明确指令选择“保留历史”或“不保留”；未说明时先确认，不擅自决定。首次新增没有被替换版本时无需此选择。选择保留时，旧版本及旧设计依赖的 CAD、图纸、俯视资源、BOM 与必要资料先登记到 `library/history`；选择不保留时，不归档本次被替换版本。
- 历史定义按原 ID、修订与来源哈希追溯，冻结其必要依赖；共享相同内容可以去重，但必须保留可解析的受保护引用。不得让同一旧身份静默改指新几何，不为保留少数依赖复制整库快照。
- `library/history` 中的元件供旧工程解析、渲染及使用原配套资料；不出现在新建元件选择列表，不允许从列表拖入或通过新增入口用于新设计。已有实例仍可打开和渲染，历史状态不能误作缺失或不支持显示。
- 更新记录用户当次的保留选择、旧工程的 ID、版本锁及实际依赖；选择保留时，验证历史文件可读、哈希和引用完整后再切换现用版本。旧工程不自动升级；未带足够版本信息时使用有证据的兼容映射，无法确定则报告，不猜测替换。
- 项目保留当前最终工程 JSON 和必要当前成果；项目 `history` 仍只放人工确认或正式交付的工程 JSON 里程碑。旧元件依赖统一进入 `library/history`，不为此保留全部旧引擎、项目模型、整套加工/客户包或自动保存。
- 入库事务可以清理已被正式采用或历史登记覆盖的临时回滚副本。`library/history` 及其引用资源不是缓存、孤立资源或清理候选；清理必须同时核对现用、历史及项目引用。
- 只增量保存新增/变更的当前资料和历史依赖，未变文件不动、不重复验收、不重压整库。外接盘的当前交付保留规则不得用于删掉历史依赖；历史版本以独立身份保留，并非被覆盖的同一当前交付。
- 保留来源、验收范围、项目引用与缺项记录；不以恢复文件冒充新的几何、实物或制造验收。未知或缺失依赖如实列出，不能声称旧设计已可精确复现。

冻结输入工程、元件修订、每个加工文件和 BOM 的 SHA256。按加工零件列数量、材料、表面处理、螺纹与装配要求；外购件另列采购清单。每个可加工件提供对应 STEP 和可读工程图；DXF 只作为补充，不替代三视图。激光刻字包含字体/位置、实际刻字文本、DXF 和定位图及对应哈希。

## 2D 工程图行业规范（2026-11-26 生效，取代旧版省略公差与粗糙度条款）

- **STEP 与 2D 图分工**：单件 3D STEP 供 CAM 编程；2D 加工图只表达外形、定位与配合尺寸、公差、粗糙度、孔/螺纹/沉孔符号、倒角、材料与表面处理。严禁用大段文字或 `U/V`、`Z0/Z11`、`Y=-4` 等程序局部坐标代替视图尺寸标注；装配顺序、名义光高、内部审核状态与哈希追溯移出加工图面。
- **投影与标题栏**：全线统一第一角法（GB 国标），附标准第一角投影符号与固定在右下角的标准标题栏。默认未注公差 `GB/T 1804-m`（ISO 2768-m）、默认粗糙度 `Ra 3.2`（配合/光学基准面单标 `Ra 1.6`）、内螺纹公差带 `6H`；精密销孔等直接标注专用公差。
- **视图、剖视与技术要求**：盲孔、沉孔及内部台阶必画剖视图（A-A）或隐藏虚线并直接标深；所有圆孔画中心十字线；技术要求控制在 5 条极短句以内。
- **面包板底板精简规则**：底板加工图默认 1 页（外形尺寸 + 板厚 + M6 阵列标注 + 沉孔气泡与简表，不打几百行规则网格全孔表）；底板镭雕定位图缩至 1–2 页（裸板顶面定位 + 侧壁 Logo 放大定位，删除整页逐字坐标明细表）。详规见 [行业 2D 制图规范](../../drawing-standard.md)。

倒 C 角按 统一规则 核对：实际 STEP、加工图和修订对应，标明 C 值/角度、适用边组及功能例外；复用已有倒角验收，只补新增或受影响项。不能用“去毛刺”文字替代已确认但尚未建模的倒角。

使用引擎 exports 的原验收约束；专业预览警告不能被删除后作为放行依据。缺图、缺尺寸、未核查的孔或未确认版本写入 blocking-items.json。未解除制造阻塞时交付 review 状态，不冠以 ready。

输出放 projects/<project>/results/manufacturing，附 manifest.json、验收记录和 README.md。验证压缩包可解压、清单内所有文件哈希一致、数量与已冻结工程一致，再追加日志。
