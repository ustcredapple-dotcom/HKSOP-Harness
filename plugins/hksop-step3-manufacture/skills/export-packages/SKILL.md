# 三维总装与交付

阅读 [交付文件清单](references/packages.md) 与 [行业 2D 制图规范](references/drawing-standard.md)。核对输入项目、空间回执与源资产哈希，用冻结的制造档案分别导出加工和客户包。

2D 加工图必须按第一角法、视图直标尺寸（含必要剖视与中心线）、右下角标题栏及 `GB/T 1804-m` / `Ra 3.2` / `6H` 默认标准出图；严禁用长段落文字替代尺寸标注；底板加工图默认 1 页、镭雕定位图缩至 1–2 页，并逐页渲染成图像视觉验收。

在本技能目录使用下列入口。文件路径可使用绝对路径。

```sh
python3 scripts/export_packages.py --help
```

## 保偏接口与验收

总装回读逐个检出真实光纤插头和尾套，核对朝向、板缘、中央工作距、双端余量与全行程干涉。总装、加工图和打标使用同一坐标，采购清单按标准规格归并并保留数量来源。校验 CSV、JSON、压缩包及实模的 SHA256。
