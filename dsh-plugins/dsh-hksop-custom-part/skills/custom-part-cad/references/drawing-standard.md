# HKSOP 行业 2D 加工工程图规范（2026-11-26）

本规范自 2026-11-26 起生效，**正式取代**旧版省略通用公差与粗糙度的条款，适用于所有提交给加工商的定制加工件、底板及模块 2D 工程图。

## 1. 3D STEP 与 2D 工程图职责分工

- **3D STEP 供 CAM 编程，2D 图纸供工艺要求与 QC 检验**：现代机加工以单件 3D STEP 作为三维加工依据；2D 加工图必须集中、直观地表达外形总尺寸、关键配合与定位尺寸、公差、粗糙度、螺纹/沉孔/销孔规格、倒角、材料及表面处理。
- **严禁以大段段落文字替代尺寸标注**：禁止在图纸空白处用“小作文”描述零件形状和坐标，严禁直接打印 CAD 或脚本的局部坐标系描述（如 `U±10, V±11.5`、`底面 Y=-4, 顶面 Y=33.5`、`Z0/Z11`、`STEP 用底孔简化建模` 等）。
- **非机加工信息一律移出 2D 加工图面**：装配先后顺序、系统名义光高、光学追迹说明、内部审核备注（如 `首件待确认`、`螺纹等级待确认`）、源文件 SHA-256 及路径追溯信息不得印在加工图纸上，统一放在装配说明或内部回执。

## 2. 投影法、图框与右下角标准标题栏

- **全线统一第一角法（GB 国标）**：主视图为主基准，俯视图放在主视图正下方，左视图放在主视图正右方（右视图放在主视图正左方）。禁止同一张图或同一加工包内第一角法与第三角法混用。
- **标题栏与投影符号**：每张工程图必须带有标准图框及固定在**右下角**的标准标题栏，清晰标明：图号/修订、零件名称、本套加工数量、材料、表面处理、未注公差标准、默认表面粗糙度、未注内螺纹公差带、比例、单位（`mm`）、页码以及标准**第一角投影符号**。
- **视图比例**：优先选用标准工程图比例（如 `1:1`、`2:1`、`1:2`、`1:5`），同页主正交视图尽量保持一致比例；局部放大图或独立比例视图须就近标明自身比例。

## 3. 默认公差、粗糙度与螺纹精度

未在尺寸旁单独注明时，全图默认执行以下行业通用标准（并在右下角标题栏或技术要求首条明确标出）：

| 项目 | 默认行业标准 | 关键特征/专用要求处理 |
| --- | --- | --- |
| 未注线性与角度公差 | **`GB/T 1804-m`**（等效 **`ISO 2768-m`**） | 精密孔距、安装台阶高、配合边等关键尺寸直接在尺寸线旁标具体上下偏差 |
| 默认表面粗糙度 | **`Ra 3.2`** | 光学安装贴合面、基准面、精密导向面按需单独标注 **`Ra 1.6`** 或更高要求 |
| 未注内螺纹公差带 | **`6H`**（外螺纹默认 `6g`） | 特殊配合螺纹直接按具体公差带标注 |
| 精密定位销孔 | 视图直接标专用公差 | 如 `Ø2.01 +0.02/0` 或对应 `H7` 配合公差，不得留空待定 |

## 4. 视图表达、剖视与标注铁律

- **隐藏内部特征必须表达清楚**：凡有盲孔、沉孔、内部台阶或内凹槽的零件，必须在对应正交视图绘制**剖视图（如 A-A 全剖/阶梯剖）**或清晰隐藏虚线，并直接在视图上标出孔深、沉孔深与台阶高度。
- **中心线与测量基准**：所有圆孔与孔轴必须绘制中心十字线或轴心线；必须在主视图或俯视图明确标注工艺基准（如底面、贴合边、基准孔 `A / B` 或原点标记），严禁让加工商自行换算局部坐标。
- **尺寸直接在视图标注**：长宽高外轮廓、底座厚度、柱身直径、台阶高、圆角 `R`、倒角 `C0.3`、孔距尺寸链及关键角度必须在视图上用尺寸线和箭头直接标出。
- **技术要求（Notes）严格 ≤ 5 条极短句**：仅列机加工与质检必需条文，例如：
  1. 未注尺寸公差按 GB/T 1804-m（ISO 2768-m）。
  2. 未注表面粗糙度 Ra 3.2。
  3. 未注外棱倒角 C0.3×45°，锐边去毛刺。
  4. 内螺纹按 6H；零件加工后按材料要求去磁、表面处理。
  5. 其余几何形状参照同修订 3D STEP 模型。

## 5. 紧凑行业孔标与符号

同规格孔合并数量并就近使用短引线直指孔口或剖视孔特征，避免用空泛文字描述代替：

| 孔型 | 标准紧凑标注示例 | 说明 |
| --- | --- | --- |
| 同规格通孔 | `4× ⌀6.4 通` | 标明数量、孔径与贯穿 |
| 圆柱沉孔 | `4× ⌀6.6 通 / ⌴⌀11 ↧6.5` | 分两行紧凑标注；双面加工时加注 `顶面` 或 `底面` |
| 锥形沉头 | `2× ⌀4.3 通 / ⌵⌀8.5×90°` | 注明沉头直径与锥角 |
| 贯穿内螺纹 | `4× M6-6H` 或 `4× M4×0.7-6H` | 贯穿螺纹省略“通”字，避免与过孔混淆 |
| 盲内螺纹 | `2× M4×0.7-6H ↧8`（必要时附 `底孔 ⌀3.3 ↧10.5`） | 直接标有效牙深；底孔深按需单列 |
| 定位销盲孔 | `4× ⌀2.01 +0.02/0 ↧4.2` | 直接在尺寸上标公差与直壁深 |

> 若当前字体缺 `⌀ / ↧ / ⌴ / ⌵`，允许用 `Ø`、短词 `深`、`沉孔`、`沉头` 替代，严禁输出空框乱码。

## 6. 面包板底板精简出图规范

- **底板加工图默认 1 页**：
  - 视图直接标注板长、板宽、主/侧视板厚 `t`、基准边距及 M6 规则网格阵列尺寸（如 `15×12.5=187.5`、`274× M6-6H`）；
  - 安装沉孔及非规则孔在图上画中心十字线、打气泡编号（`H1, H2...`）并用引线标注 `K× ⌀6.6 通 / ⌴⌀11 ↧6.5`；
  - 右侧仅放精简的**沉孔/异形孔坐标简表**与 **≤ 5 条技术要求**；**默认不再打印几百行规则 M6 网格全孔坐标表**（规则孔位以阵列尺寸及同版 3D STEP 为准）。
- **底板镭雕定位图缩至 1–2 页**：
  - 仅包含「裸板顶面定位总览（标清 1:1 mm DXF 原点、外形定位尺寸与边距余量）」与「朝外侧壁 HKSOP 黑白 Logo 放大定位（距右 3 mm、上下各 1.5 mm）」；
  - **删除整页逐字/逐框坐标明细表**（激光打标机直接导入随包的 1:1 mm 闭合矢量 DXF）。

## 7. 出图视觉自检打回门槛

所有新生成或修改的加工 PDF / SVG 必须渲染成图像逐页查看。命中以下任一项直接判为**不通过**，必须修改重出：

1. 图面仍出现长段落文字或脚本局部坐标（`U/V`、`Y=-4`、`Z53` 等）替代视图尺寸线；
2. 有盲孔、沉孔或内部台阶但视图无剖视、无隐藏虚线或未直接标出深度；
3. 缺失右下角标准标题栏、缺失第一角投影符号、缺失 `GB/T 1804-m` 或 `Ra 3.2`；
4. 技术要求超过 5 条，或夹带装配顺序、光高、SHA 哈希、待定推诿语；
5. 第一角法与第三角法混用，或出现尺寸、引线、文字、页脚重叠与裁切；
6. 规则孔阵面包板打印整页 M6 全孔坐标表，或镭雕定位图附带整页逐字坐标明细表。
